# juanmazaragoza.com

Personal site of Juan Manuel Zaragoza. Static HTML generated by a zero-dependency Node script and served by GitHub Pages from the `main` branch root (custom domain via `CNAME`, Cloudflare in front).

## Structure

```
├── src/                 # Page bodies (home, work, services, about, contact, 404) with {{placeholders}}
├── data/
│   ├── pages.json       # Title, description and path of each static page
│   ├── projects.json    # Case studies (one page each under /work/<slug>/)
│   └── images.json      # WebP dimensions, generated by scripts/optimize-images.sh
├── scripts/
│   ├── build.mjs        # Generates index.html, */index.html, work/*/index.html, 404.html, sitemap.xml
│   └── optimize-images.sh  # Converts referenced images to WebP (needs ImageMagick)
├── css/style.css
├── js/main.js           # Progressive enhancement only (menu, filters, FAQ, video, animations)
└── images/
```

Generated files (`index.html`, `work/`, `services/`, `about/`, `contact/`, `404.html`, `sitemap.xml`) are committed, because GitHub Pages serves the repo as-is. Do not edit them by hand: edit `src/` or `data/` and rebuild.

## Workflow

```bash
# after adding or changing images (requires ImageMagick: brew install imagemagick)
npm run images

# regenerate all pages and the sitemap
npm run build

# preview at http://localhost:8000
npm run serve
```

Then commit everything, including the generated HTML, and push to `main`.

## Rules that keep GitHub Pages happy

- Keep `CNAME` and `.nojekyll` at the root.
- Use lowercase file names and reference them with the exact same case (Pages is case-sensitive, macOS is not).
- Internal links always end with `/` (`/work/<slug>/`).
- Redirects and security headers (HTTPS, HSTS) are configured in Cloudflare, not here.
