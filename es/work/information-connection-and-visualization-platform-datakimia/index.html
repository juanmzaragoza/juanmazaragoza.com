El Desafío

Datakimia es un SaaS de analytics multi-tenant white-label (EE.UU.): cada cliente está aislado en su propio deployment. El desafío: entregar BI embebido y agentes de IA conversacional de datos seguramente per-customer, y mantener la capa de BI (fork de Apache Superset con ~430 commits personalizado) actualizada sin romper producción.

Lo Que Construí

Backend NestJS (37 Endpoints)

Fundé y creé el backend de producción (primer commit May 2024): login Google/Microsoft Entra/Auth0, tokens JWT, control de acceso basado en roles derivado de permisos de Superset, autorización basada en CASL, aislamiento de datos per-customer. Grado de producción para 2+ años sin downtime orientado a clientes.

Embedding de Superset & RBAC

Generación de guest tokens para dashboards embebidos con filtros de seguridad de nivel de fila aplicados per-customer. Filtrado de dashboard dinámico por contexto de customer. Embedding seguro en iframe en el frontend de Next.js.

Agentes de IA Conversacional de Datos

Construí exploración de datos basada en chat sobre BigQuery usando Google Gemini Data Analytics API (respuestas SSE streaming). Implementé agente de voz con Gemini Live API para queries de datos habladas. Los usuarios hacen preguntas en lenguaje natural; el agente traduce a SQL de BigQuery y devuelve insights.

Migración Apache Superset 4.1 → 6.1

Migré el fork de Superset altamente customizado de Datakimia en 3 versiones mayores (8 Sep – 7 Oct 2024, ~30 días de calendario). Proceso:

  • Inventario de ~430 commits personalizado clasificados en carry/replace/drop
  • 6 upstream merges con resolución de conflictos asistida por IA (Cursor) dentro de checks determinísticos
  • Merge final tocó ~4,400 archivos
  • 23 checks de wiring automatizados; detectaron 3 features que habían silenciosamente roto
  • Test de humo de 5-fases, 17-pasos (local → ephemeral → pilot → preprod → prod)
  • Esfuerzo: ~100 horas en 30 días

Stack

Next.js 14 (frontend), NestJS 10 (backend), Prisma ORM, PostgreSQL, Apache Superset, BigQuery, Google Gemini, GKE, Helm.
