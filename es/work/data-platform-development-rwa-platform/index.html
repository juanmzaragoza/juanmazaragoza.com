Plataforma de Datos RWA — Next.js + BigQuery

Aplicación web integrando múltiples fuentes de datos en un warehouse BigQuery con una capa de API Python Flask para querying en tiempo real

RWA Insights · Fintech / Data Analytics · EE.UU. · Full-Stack Developer · Feb 2024

Resultados

  • Diseños complejos de Figma replicados con precisión
  • Querying de datos en tiempo real vía API Flask
  • Insights accionables desde warehouse BigQuery

Contribuí al Proyecto de Plataforma RWA en un período de tres semanas, jugando un papel pivotal en desarrollar una solución basada en Next.js. Usando mockups detallados de Figma como blueprint, ayudé a diseñar y construir una aplicación web que integra datos de varias fuentes en un data warehouse de BigQuery.

Arquitectura

Python Flask fue usado para construir una capa API eficiente, habilitando querying en tiempo real e integración de datos sin fricciones. Este acceso de datos streamlineado permitió al cliente ganar insights accionables y mejorar eficiencia operacional.

Resultado

Demostré la habilidad de replicar mockups complejos de Figma con precisión, integrar tecnologías avanzadas como BigQuery y Flask, y aprovechar herramientas web modernas para mejorar business intelligence y facilitar toma de decisiones data-driven.
