Scraping PDF Veterinario — IVEE

Scripts Node.js en GCP para extraer datos médicos de registros PDF de pacientes caninos, almacenando resultados en BigQuery para visualización en dashboards

TechNode.js
TechGCP
TechFirebase
TechBigQuery
TechCloud Functions

IVEE · Tech Veterinario · EE.UU. · Backend Developer · Ene 2021 – Ene 2022

Resultados

  • Extracción automática de datos PDF a escala
  • Diseño modular de scraper para múltiples formatos de PDF
  • Analytics de BigQuery habilitando insights veterinarios

Para IVEE, una compañía veterinaria dedicada al cuidado integral de animales, desarrollé scripts sofisticados para streamline la extracción de información médica vital de archivos PDF conteniendo historiales médicos de pacientes caninos.

Arquitectura

  • Google Storage bucket como repositorio para PDFs subidos por veterinarios
  • Cloud Function automaticamente triggered upon cada recepción de archivo
  • La función lee y scrapes contenidos PDF basado en el scraper asociado para cada formato de sistema
  • Diseño modular: nuevos formatos PDF acomodados agregando nuevas funciones de scraping
  • Datos extraídos persistidos en BigQuery para análisis cross-departamento
  • Dashboards interactivos proporcionando veterinarios insights en salud de pacientes e historia de tratamiento

El proyecto se extendió más de un año y ejemplificó la dedicación requerida para abordar desafíos complejos en healthcare veterinario a través de tecnología.
