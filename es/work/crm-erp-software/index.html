Desarrollé dos soluciones de software a medida para un cliente basado en España que revolucionaron sus operaciones de negocio.

Frontend ERP

Construí un frontend ERP altamente adaptable y user-friendly usando React.js. El framework permitió creación de experiencia de usuario dinámica y responsive, empoderando usuarios para interactuar sin fricciones con sus datos. Integré con un backend Java robusto asegurando flujo de datos suave y ejecución eficiente de lógica de negocio.

Projects Organization — SSO

Un endeavor ambicioso: una aplicación web centralizando acceso a múltiples aplicaciones a través de una solución Single Sign-On (SSO). Proporcionó rastreo integral de recursos a través de varios proyectos. Aprovechando MariaDB como plataforma de base de datos, con un servidor backend Java orquestando integración sin fricciones de datos y funcionalidades.
