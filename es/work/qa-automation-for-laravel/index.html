Plataforma de Ticketing: Automatización E2E QA

Tests E2E con Playwright, tests de integración con Pest, y dashboards de Superset — eliminando regresiones manuales, mejorando estabilidad y escalabilidad

Plataforma Premium de Ticketing · Ticketing & Eventos · España, América Latina · Ingeniero QA · Ene 2025 – Presente

Resultados

  • Suite E2E integral cubriendo flujos críticos de checkout
  • 600+ casos de test de integración en backend en flujos críticos
  • 3 navegadores cubiertos (Chromium, Firefox, WebKit)
  • 3 puertas de pago testeadas end-to-end incluyendo flujos 3D Secure
  • Aproximadamente 15–20 horas de regresión manual por release eliminadas

El Desafío

Una plataforma de ticketing y gestión de eventos white-label (monolito Laravel desde 2017) manejando flujos de checkout de alto volumen en España y América Latina. Flujos de ingresos — creación de eventos, entrega de tickets, pagos a través de 3 puertas de pago — no tenían cobertura end-to-end. Los releases dependían completamente de testing manual.

  • Sin suite E2E existente; testing manual era insostenible
  • Flujos críticos (checkout, códigos de descuento, reenvío de tickets vía email/WhatsApp) carecían de automatización
  • Múltiples puertas de pago incluyendo flujos 3D Secure sin testear
  • Stakeholders de negocio carecían de visibilidad en tiempo real del rendimiento de la plataforma

Lo Que Construí

Suite E2E con Playwright

Diseñé la estrategia completa de testing desde cero como propietario de la suite E2E. Construí una suite integral de Playwright + TypeScript que corre después de cada deploy en sandbox y staging: una puerta crítica de tests @critical primero, luego cobertura completa en Chromium, Firefox y WebKit. Testeé checkout end-to-end con todas las 3 puertas de pago incluyendo flujos 3D Secure. Usé test users pre-creados en lugar de registro vía email para garantizar tests determinísticos y rápidos.

Tests de Integración con Pest

Escribí tests de integración robustos cubriendo endpoints de API y lógica de negocio crítica: endpoints /check, /resend, /me, /sessions; validaciones de permisos basados en roles (seller, admin, whitebrand); validación de códigos de descuento y gestión de cupones.

Fork de Superset & Embedding

Introduje Apache Superset (fork) dentro de Docker; integré Google OAuth e integración segura basada en tokens en Laravel con filtrado de nivel de fila por organizador. Habilité dashboards en tiempo real en ventas de tickets, actividad de sesión, y comportamiento de usuarios.

Observabilidad de Tests & CI/CD

Construí una herramienta interna de métricas (Node, Prisma, PostgreSQL, Chart.js) para rastrear tests flaky y duración de tests por commit. Mejoré pipelines de GitLab CI; estandaricé templates de PR y documentación interna.

Stack

Laravel 12, PHP 8.4, Playwright, TypeScript, Pest, React 19, Apache Superset, GitLab CI, PostgreSQL.
