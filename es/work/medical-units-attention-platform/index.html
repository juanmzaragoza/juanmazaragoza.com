El Desafío

Gestionar dispensación de medicamentos en farmacias afiliadas en nombre del Gobierno de la Ciudad de Buenos Aires. Requerimientos: monitorear operaciones de dispensación, gestionar subsidios, analizar tendencias de demanda de medicinas, asegurar trazabilidad completa, e implementar medidas preventivas para continuidad de cadena de suministro.

Liderazgo Técnico

Seleccioné el technology stack: Angular (frontend), Java Spring Boot 2 (backend), MariaDB (base de datos). Colaboré estrechamente con analistas y Product Owner para definir reglas de negocio. Lideré el equipo usando metodologías de desarrollo ágil, asegurando adherencia a deadlines mientras entregaba un producto de alta calidad. Instituí robustas prácticas de entrega de código habilitando al equipo QA del gobierno trabajar independientemente.

Objetivos del Sistema

  • Monitorear farmacias dispensando medicinas subsidiadas por el gobierno
  • Gestionar subsidios y analizar estadísticas en tipos de medicinas más necesitadas
  • Implementar medidas preventivas para continuidad de cadena de suministro
  • Asegurar trazabilidad completa de todas las operaciones de distribución

Stack

Angular, Java Spring Boot 2, JPA, QueryDSL, OpenAPI, MariaDB.
