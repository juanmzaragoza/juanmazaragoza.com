El Desafío

Evaluar sistemáticamente, continuamente, y objetivamente desempeño de empleados en todos los departamentos de la Ciudad de Buenos Aires. Requerimientos: definir criterios de desempeño basados en rol, identificar necesidades de training, promover fairness y transparencia, y habilitar adaptación ágil conforme objetivos organizacionales evolucionaban.

Liderazgo Técnico (3 Generaciones)

Trabajé en todas las tres generaciones de este sistema:

  • Generación 1 (Symfony 2): 2014–2015, 200 de 356 commits — la plataforma inicial
  • Generación 2 (LoopBack): 2018 — capa de API de integración
  • Generación 3 (Angular + Java Spring Boot): 2019–2020, tech lead de frontend — la versión actual

Gen 3: Liderazgo Técnico

Stack seleccionado: Angular (frontend), Java Spring Boot (backend), PostgreSQL (base de datos). Definí reglas de negocio con analista y Product Owner. Introduje metodología ágil y establecí proceso de entrega eficiente habilitando al equipo QA del gobierno trabajar independientemente. Colaboré con representantes de sindicato de trabajadores para asegurar fairness y transparencia en criterios de evaluación.

Objetivos del Sistema

  • Evaluar sistemáticamente desempeño de empleados contra requerimientos de rol
  • Identificar necesidades de training y diseñar planes de mejora a corto plazo
  • Mejorar comunicación para lograr objetivos organizacionales predefinidos
  • Promover transparencia, objetividad, equidad, e imparcialidad

Plataforma En Vivo

El sistema de evaluación está en vivo en evaluaciongcaba.buenosaires.gob.ar.

Contexto Más Amplio

Sobre ~7 años (2014–2020) en Buenos Aires City, serví como tech lead en casi todos los sistemas desarrollados, autorizando 1,733 commits en 26 repositorios y gestionando 5 stacks de tecnología diferentes (Symfony 2, Angular, Java Spring Boot, React, Azure/.NET).

Stack

Angular, Java Spring Boot, PostgreSQL, OpenAPI, Ágil.
