CRM Development — Cloudin & Omnisauto

Enhanced and customized two Spanish CRM platforms with Laravel, seamlessly integrated with WordPress via custom API endpoints

Cloudin, Omnisauto · Business Software · Spain · Full-Stack Developer · Feb 2024

Results

  • Two CRM platforms enhanced and customized
  • WordPress integration via custom API endpoints
  • Improved data synchronization and performance

For Cloudin and Omnisauto, my task was to enhance existing CRM functionalities and tailor them to specific client needs using Laravel PHP, JavaScript, and MariaDB.

Core Development

Modified the core codebase focusing on entity creation, billing processes, and dashboard customization. Leveraging Laravel's ORM capabilities, optimized database queries and improved data retrieval performance for efficient handling of large datasets.

WordPress Integration

One of the significant challenges involved integrating these CRMs with a WordPress platform to synchronize all data seamlessly. By developing custom API endpoints and data transfer protocols, established a robust connection enabling real-time data exchange between the CRM systems and WordPress.

Outcome

Significant improvement in the functionality and usability of both platforms. Clients benefited from streamlined processes, intuitive interfaces, and enhanced capabilities that empowered them to operate more efficiently in their respective domains.
