AWS Lambdas & React Native — Indigo

Lambda functions to consolidate React Native app backend logic, plus performance optimization and team documentation for a lifestyle startup

TechAWS Lambda
TechReact Native
TechNode.js

Indigo · Health & Wellness · US · Full-Stack Developer · Feb 2022

Results

  • Modular Lambda function architecture
  • Performance improvements for React Native app
  • Comprehensive team documentation

Indigo was confronted with the complex task of developing a versatile backend capable of managing the intricate business logic of their lifestyle application — nutrition, workout, and meditation — which was previously integrated within their React Native platform.

Backend Architecture

Crafted a sophisticated backend architecture by implementing a series of Lambda functions. These were strategically designed to consolidate and optimize the application logic, resulting in a robust and scalable backend infrastructure. By modularizing the codebase, ensured that Indigo's backend was not only efficient but also highly adaptable to future modifications.

Performance & Documentation

Provided ongoing support for the React Native app, conducting in-depth performance analyses and implementing targeted enhancements. Organized and documented the web application and development team — establishing clear guidelines, documentation protocols, and communication channels to streamline collaboration.
