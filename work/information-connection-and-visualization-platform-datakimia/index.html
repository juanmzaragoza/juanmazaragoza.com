Data Platform — Datakimia

Full-stack data platform with Next.js, NestJS, Superset embedded reports, and per-client dynamic filtering

TechNext.js
TechNestJS
TechSuperset
TechPostgreSQL
TechBigQuery
TechPython

To meet Datakimia's needs, I developed a platform that seamlessly connects information and provides efficient data visualization, ensuring a smooth user experience and quick report delivery. The stack: Next.js (frontend), NestJS (backend), PostgreSQL, and Superset.

Key Features

  • Superset API integration to embed reports with per-client dynamic filtering
  • Redis implementation for fast data store and enhanced performance
  • Frontend hosted on Vercel with GitHub Actions for automated deployments
  • Superset customizations in both Python backend and React frontend components
  • Role-based user authentication and authorization for secure data access

Ongoing Development

This project remains an ongoing effort, with continuous improvements to ensure scalability and adaptability to Datakimia's long-term growth. Working in parallel on other initiatives, I've demonstrated the ability to effectively manage priorities and deliver results in a complex data-driven environment.
