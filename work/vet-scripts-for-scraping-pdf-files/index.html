Vet PDF Scraping — IVEE

Node.js scripts on GCP to extract medical data from canine patient PDF records, storing results in BigQuery for dashboard visualization

TechNode.js
TechGCP
TechFirebase
TechBigQuery
TechCloud Functions

IVEE · Veterinary Tech · US · Backend Developer · Jan 2021 – Jan 2022

Results

  • Automated PDF data extraction at scale
  • Modular scraper design for multiple PDF formats
  • BigQuery analytics enabling veterinary insights

For IVEE, a veterinary company dedicated to comprehensive animal care, I developed sophisticated scripts to streamline the extraction of vital medical information from PDF files containing canine patient medical histories.

Architecture

  • Google Storage bucket as the repository for PDFs uploaded by veterinarians
  • Cloud Function automatically triggered upon each file reception
  • The function reads and scrapes PDF contents based on the associated scraper for each system format
  • Modular design: new PDF formats accommodated by adding new scraping functions
  • Extracted data persisted in BigQuery for cross-department analysis
  • Interactive dashboards providing veterinarians insights into patient health and treatment history

The project spanned over a year and exemplified the dedication required to address complex challenges in veterinary healthcare through technology.
