The Challenge

Systematically, continuously, and objectively assess employee performance across all Buenos Aires City departments. Requirements: define role-based performance criteria, identify training needs, promote fairness and transparency, and enable agile adaptation as organizational goals evolved.

Technical Leadership (3 Generations)

I worked on all three generations of this system:

  • Generation 1 (Symfony 2): 2014–2015, 200 of 356 commits — the initial platform
  • Generation 2 (LoopBack): 2018 — integration API layer
  • Generation 3 (Angular + Java Spring Boot): 2019–2020, technical lead of frontend — the current version

Gen 3: Technical Leadership

Selected stack: Angular (frontend), Java Spring Boot (backend), PostgreSQL (database). Defined business rules with analyst and Product Owner. Introduced agile methodology and established an efficient delivery process enabling the government QA team to work independently. Collaborated with labor union representatives to ensure fairness and transparency in evaluation criteria.

System Goals

  • Systematically evaluate employee performance against role requirements
  • Identify training needs and devise short-term improvement plans
  • Enhance communication to achieve predefined organizational objectives
  • Promote transparency, objectivity, equity, and impartiality

Live Platform

The evaluation system is live at evaluaciongcaba.buenosaires.gob.ar.

Broader Context

Over ~7 years (2014–2020) at Buenos Aires City, I served as technical lead on nearly all systems developed, authoring 1,733 commits across 26 repositories and managing 5 different technology stacks (Symfony 2, Angular, Java Spring Boot, React, Azure/.NET).

Stack
