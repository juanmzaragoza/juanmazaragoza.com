Performance Evaluation Platform — Buenos Aires Gov

Technical Lead for a city-wide employee performance evaluation system — Angular, Java Spring Boot, PostgreSQL, with agile methodology

TechAngular
TechJava Spring Boot
TechPostgreSQL
TechAgile

Served as Technical Lead for a performance evaluation system commissioned by the Buenos Aires City Government — designed to systematically, continuously, and objectively assess employee performance across city departments.

System Goals

  • Systematically evaluate employee performance against role requirements
  • Identify training needs and devise short-term improvement plans
  • Enhance communication to achieve predefined organizational objectives
  • Promote transparency, objectivity, equity, and impartiality

Technical Leadership

Selected the technology stack: Angular (frontend), Java Spring Boot (backend), PostgreSQL (database). Defined business rules with the analyst and Product Owner. Introduced agile development methodology and devised an efficient code delivery process enabling the QA team to work independently.

The evaluation process involved representatives from labor associations to ensure fairness. The platform is live at evaluaciongcaba.buenosaires.gob.ar.
