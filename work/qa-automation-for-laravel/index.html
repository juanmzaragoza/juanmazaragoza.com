Premium Ticketing Platform · Ticketing & Events · Spain, Latin America · QA Engineer · Jan 2025 – Present

Results

  • Comprehensive E2E test suite covering critical checkout flows
  • 600+ backend integration test cases across critical flows
  • 3 browsers covered (Chromium, Firefox, WebKit)
  • 3 payment gateways end-to-end tested including 3D Secure
  • Roughly 15–20 hours of manual regression per release replaced

The Challenge

A white-label ticketing and event management platform (Laravel monolith since 2017) handling high-volume checkout flows across Spain and Latin America. Revenue flows — event creation, ticket delivery, payments through 3 gateways — had no end-to-end test coverage. Releases relied entirely on manual regression.

  • No existing E2E test suite; manual testing was unsustainable
  • Critical flows (checkout, discount codes, ticket resend via email/WhatsApp) lacked automation
  • Multiple payment gateways including 3D Secure flows were untested
  • Business stakeholders lacked real-time visibility into platform performance

What I Built

Playwright E2E Test Suite

Designed the entire testing strategy from scratch as owner of the E2E suite. Built a comprehensive Playwright + TypeScript suite that runs after every deploy to sandbox and staging: a critical gate of @critical tests first, then full coverage on Chromium, Firefox and WebKit. Tested checkout end-to-end with all 3 payment gateways including 3D Secure flows. Seeded test users instead of relying on email registration to ensure deterministic, fast tests.

Pest Integration Tests

Wrote robust integration tests covering API endpoints and critical business logic: /check, /resend, /me, /sessions endpoints; role-based permission checks (seller, admin, whitebrand); discount code validation and coupon management.

Superset Fork & Embedding

Introduced Apache Superset (fork) inside Docker; integrated Google OAuth and token-based secure embedding in Laravel with per-organizer row-level filtering. Enabled real-time dashboards on ticket sales, session activity, and user behavior.

Test Observability & CI/CD

Built an internal metrics tool (Node, Prisma, PostgreSQL, Chart.js) to track flaky tests and test duration per commit. Improved GitLab CI pipelines; standardized PR templates and internal documentation.

Stack

Laravel 12, PHP 8.4, Playwright, TypeScript, Pest, React 19, Apache Superset, GitLab CI, PostgreSQL.
