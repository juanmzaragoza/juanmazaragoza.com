Real Estate Platform — Listing Los Cabos: From Inherited to Profitable

Rescued a half-built React + Firebase platform, added Stripe subscriptions and security, now serving two cities from one codebase

TechReact
TechNode.js
TechFirebase
TechStripe

Listing Los Cabos · Real Estate · Mexico · Lead Developer & Project Owner · Apr 2024 – Jul 2025

Results

  • 2 cities/brands (Los Cabos, Mexico City) from one codebase
  • 3 paid subscription plans (10/30/50 listings) with 60-day free trial
  • ~10 agents managing their listings on the platform
  • From paper and Excel to live portal with full property visibility and development promotion

The Situation

A real estate portal for Los Cabos and Mexico City — half-built by previous developers in 2023, no unified property view, one person held all knowledge, property promotion was manual. The client lacked ownership of code and hosting.

The Challenge

  • Inherited codebase with incomplete features and no test coverage
  • No integration with Google Maps; property creation broken
  • Manual property promotion and activation
  • No subscription model or payment processing
  • Security issues: hardcoded keys, unvalidated Firebase access
  • Client unable to scale to a second city without external help

What I Built

Search & Discovery

Built a searchable property listing with filters (price, bedrooms, amenities) and an interactive Google Maps view. Integrated Google Maps for address autocomplete and geocoding.

Property Management

Property creation and editing workflows with image/video upload to Firebase Storage, status tracking (draft/active/sold), and agent profile assignment. Responsive design across devices.

Stripe Subscription System

Integrated Stripe payments end-to-end: checkout flow, webhooks for subscription lifecycle (creation, renewal, cancellation), plan limits (10/30/50 active listings per tier), 60-day free trial, discount codes. Each subscription tier unlocks different capabilities.

Security & Backend

Replaced hardcoded Firebase keys with environment variables. Added Firebase token validation on Node.js Express serverless backend (Vercel). Implemented reCAPTCHA on contact forms.

Multi-Brand Setup

Architected one codebase serving two cities: separate hero images, branding, and agent pools. Staging and production on Vercel with automated GitHub deployments.

External Security Review

Commissioned a professional security audit before scaling to the second city, ensuring platform readiness.

Stack

React 18, Tailwind CSS, Firebase (Auth, Firestore, Storage), Node.js/Express (Vercel Serverless), Stripe, Google Maps API.
