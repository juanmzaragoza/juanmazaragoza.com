Professionals Marketplace — Guruxy

Role-based menu system and live streaming integration using Agora for a Latin American freelance marketplace

Results

  • User-role-based menu customization
  • Live streaming feature for real-time knowledge sharing
  • Improved navigation and security

My client Guruxy had two clear needs: improve menu loading with user-role-based customization, and develop a live streaming feature allowing professionals to broadcast their knowledge in real time.

Role-Based Menu System

Implemented a user-role-menu structure that allowed each authenticated user to see only the menus relevant to their profile, improving both UX and security.

Live Streaming

Integrated Agora to manage streaming windows and sessions on the site. Made backend adjustments to ensure proper synchronization of live statuses between professionals and users, enabling seamless real-time knowledge sharing.

Outcome

Significant improvement in user experience with more relevant menus and smoother navigation. The implementation of live streaming provided a new and exciting way for professionals to connect with their audience in real time.
