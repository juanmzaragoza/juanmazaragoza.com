Results

The Challenge

Manage medication dispensing at affiliated pharmacies on behalf of Buenos Aires City Government. Requirements: monitor dispensing operations, manage subsidies, analyze medicine demand trends, ensure full traceability, and implement preventive measures for supply chain continuity.

Technical Leadership

Selected the technology stack: Angular (frontend), Java Spring Boot 2 (backend), MariaDB (database). Collaborated closely with analysts and Product Owner to define business rules. Led the team using agile development methodologies, ensuring adherence to deadlines while delivering a high-quality product. Instituted robust code delivery practices enabling the government's QA team to work independently.

System Objectives

  • Monitor pharmacies dispensing government-subsidized medicines
  • Manage subsidies and analyze statistics on most needed medicine types
  • Implement preventive measures for supply chain continuity
  • Ensure full traceability of all distribution operations

Stack

Angular, Java Spring Boot 2, JPA, QueryDSL, OpenAPI, MariaDB.
